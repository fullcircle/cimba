Event-Driven Sequence

sequenceDiagram
    participant EventQ as Event Queue
    participant Arrivals as Arrival Process
    participant Visitor as Visitor Process
    participant PQ as Priority Queue
    participant Server as Server Process
    participant Departures as Departure Process

    EventQ->>Arrivals: Start
    loop Every exponential interval
        Arrivals->>Visitor: Create & Start
        Visitor->>PQ: cmb_priorityqueue_put
        Visitor-->>EventQ: Yield (suspend)
        EventQ->>Server: Start
        loop Batch processing
            Server->>PQ: cmb_priorityqueue_get
            Note over Server: Hold for ride duration
        end
        Server->>Visitor: cmb_process_resume SUCCESS
        EventQ-->>Visitor: Yield returns
        Visitor->>Departures: cmb_objectqueue_put
        Departures->>Visitor: Get & destroy
    end
    EventQ->>Arrivals: end_sim event
    Arrivals->>Arrivals: cmb_process_stop

Customer Behaviors Summary

Balking
If queue length > patience × 10,
visitor skips that attraction.
Jockeying
After patience × 5 time units,
move to shorter queue if found.
Reneging
After patience × 10 time units,
cancel queue entry and leave.
Priority
Goldcard visitors get priority 5
vs regular priority 0.
